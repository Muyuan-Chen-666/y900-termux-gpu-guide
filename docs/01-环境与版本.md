## 2. 路径与身份

| 项目 | 实机值 / 约定 |
|---|---|
| Termux HOME | `/data/data/com.termux/files/home` |
| Termux PREFIX | `/data/data/com.termux/files/usr` |
| Ubuntu rootfs | `$PREFIX/var/lib/proot-distro/containers/ubuntu/rootfs` |
| Ubuntu 用户 | `desktop`，`HOME=/home/desktop`，当前 `UID/GID = 10309` |
| X11 显示 | `:8` |
| Termux:X11 窗口标签 | `gpu-test` |
| Termux 侧 VirGL socket | `$TMPDIR/y900-gpu-vtest` |
| Ubuntu 侧同一 socket | `/tmp/y900-gpu-vtest`（靠 `--shared-tmp` 对齐） |
| 会话运行目录 | `/tmp/runtime-y900-xfce-gpu`，权限 `0700` |
| GPU 桌面配置 / 缓存 | `~/.config/y900-xfce-gpu` / `~/.cache/y900-xfce-gpu`（Ubuntu 用户 HOME 下） |
| Termux 桌面状态 / GPU 状态 | `~/.local/state/y900-xfce-gpu` / `~/.local/state/y900-gpu` |
| 本地音频 | `PULSE_SERVER=tcp:127.0.0.1:4713` |

**UID/GID 说明：** `10309` 是本机实际值，不是通用常量。换设备或重装 Termux 后必须用 `id -u` 重新读取，`prepare-ubuntu.sh` 通过 `Y900_UID` 接收该值，遇到已有 `desktop` 身份不匹配时会报错退出，不会自动改用户。

### 三种 shell 不要混用

| 入口 | 身份 | 用途 |
|---|---|---|
| 普通 Termux | `u0_aXXX` | 运行 `pkg`、`proot-distro`、`termux-x11`、`virgl_test_server_android`、`ubuntu-manager` |
| `ubuntu-manager shell` | 容器内 root（模拟） | `apt install` 等镜像内管理操作；**不是 Android Root** |
| `ubuntu-manager gpu-shell` | 容器内 `desktop` | 已继承 `DISPLAY`、D-Bus 与 GPU 变量的普通用户终端 |

`pkg` 只属于 Termux；`apt` 属于 Ubuntu 容器。不要猜 sudo 密码，也不要把 VNC 密码当 sudo 密码。

## 4. 软件源与二进制来源

实机记录显示 Termux 包来自 Play 分支的 `https://termux.net stable/main`，`termux-x11-nightly` 来自 `https://x11-packages.termux.net x11/main`。详见 [`metadata/package-origins.txt`](../metadata/package-origins.txt)。

要点：

- 当前 Play 版 Termux **不能**套用只适配 GitHub 同签名 Termux 的 `sharedUid` APK；不要为了装某个包而卸载现有 Termux 换来源。
- 不要替换成 Adreno / Turnip 或第三方 Vulkan ICD —— 本链路明确走 **Android 原厂驱动**。
- 若 `pkg` 找不到包，先核对当前分支的 `pkg search` 与仓库配置，再考虑是否启用 `x11-repo`。
- Ubuntu 24.04 仓库会持续更新，**未来重装不保证**仍是 24.04.5、同版 Mesa。

## 5. Termux:X11 偏好

实机偏好导出在 [`metadata/Termux-X11-preferences.txt`](../metadata/Termux-X11-preferences.txt)，其中与本流程相关的有：

- `fullscreen = true`
- `forceOrientation = landscape`
- `touchMode = Trackpad`
- `displayResolutionMode = custom`
- `displayResolutionExact = 1280x1024`
- `displayResolutionCustom = 1920x1280`

分辨率可在应用设置里改，也可用 `ubuntu-manager size 1600x1067` 这类命令改。**没有修改 Android 系统屏幕分辨率或刷新率。**
